## 문제

### 문제 목록

![문제 목록. 문제번호, 제목, 난이도(하 · 중 · 상 배지), 맞힌 인원, 종류가 표로 나온다. 위쪽에 전체 · 종류별문제 · 랜덤 탭과 검색창이 있다](/covers/algorithm-server/result/02-problems.png)

난이도는 색깔 배지로 구분하고, 알고리즘 종류별로 모아 보거나 랜덤으로 한 문제를 고를 수 있다.

### 문제 보기

![문제 상세 화면. 두 수의 합 문제의 번호 · 출제자 · 난이도 · 종류와 상세설명, 입력값, 출력값, 예제 입력 · 출력, 힌트가 차례로 나온다](/covers/algorithm-server/result/03-problem.png)

설명, 입출력 형식, 예제 입력 · 출력을 순서대로 두고, 힌트는 눌러야 보이게 했다.

### 코드 제출

![도전하기 화면. 언어를 JAVA로 고르고, 소스 템플릿 아래 CodeMirror 편집기에 Hello World를 출력하는 Java 코드가 들어가 있다. 아래에 제출하기 버튼과 글자 수(143 / 500)가 표시된다](/covers/algorithm-server/result/09-challenge.png)

언어를 고르고 소스 템플릿을 누르면 기본 코드가 들어간다. 코드는 CodeMirror 편집기에서 쓰고, 아래에 글자 수 제한이 함께 보인다.

### 제출 내역

![제출내역 화면. 문제번호, 회원아이디, 성공여부(맞췄습니다), 실패이유, 제출언어(JAVA), 제출일자(1분 전)가 표로 나온다](/covers/algorithm-server/result/10-history.png)

## 게시판

### 게시글 목록

![게시판 목록. 전체 · 질문 · 자유 · 강의 게시판 탭과 글쓰기, 검색창이 있고, 글 번호 · 제목 · 작성자 · 조회수 · 댓글 · 추천수 · 작성일이 표로 나온다](/covers/algorithm-server/result/05-board.png)

### 게시글과 댓글

![게시글 상세. 1번 문제 질문드립니다 글의 본문과 작성자 · 추천수 · 조회수 · 작성일, 추천 버튼이 있고, 아래에 댓글 두 개와 댓글 작성 칸, 제출하기 버튼, 게시글 목록이 이어진다. 본인 글이라 오른쪽 위에 삭제 · 수정이 보인다](/covers/algorithm-server/result/06-post.png)

삭제와 수정은 글쓴이 본인만 할 수 있다. 댓글은 페이지를 다시 불러오지 않고 바로 달린다.

### 글쓰기

![글쓰기 화면. 공지사항 안내, 제목, 카테고리(질문), 사용 언어(JAVA), 댓글 사용 여부를 고르고 아래 에디터에 본문을 쓴 뒤 제출한다](/covers/algorithm-server/result/12-write.png)

## 관리자 — 문제 등록

![관리자 문제 등록 화면. 관리자만 접근할 수 있다는 안내 아래 제목, 난이도 · 알고리즘 종류 · 힌트 사용 여부 · 언어 옵션, 상세설명 에디터, 입력값 입력칸이 이어진다](/covers/algorithm-server/result/13-admin-problem.png)
