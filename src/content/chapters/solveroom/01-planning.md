> 사진, 이미지, 초성 같은 힌트를 보고 정답을 맞히는 온라인 퀴즈 플랫폼

이 글은 1차 MVP 기준의 기획 문서입니다.

## 목표

게임, 음악, 문화, 방송, 상식, 만화, 음식, 인물, 스포츠, 병맛 등 여러 분야의 문제를 유저들이 풀 수 있다.
유저들이 자유롭게 문제를 내고, 다른 유저들이 그 문제를 맞히는 형식으로 진행한다.

## 핵심 차별점

단순히 문제를 만들고 푸는 데 그치지 않고, 점수를 이용한 랭킹제와 멀티플레이 등을 지원할 예정이다.

  가장 먼저 영감을 받은 사이트

## 기획 개요

전체적인 흐름은 **기능 기획 → 기능 명세 → 화면 기획 → 화면 명세** 순서로 진행한다.

## 기능 기획

### 문제 맞추기

문제 카드(문제 패키지) 안에 여러 문제가 들어 있는 형식으로 진행한다.

문제 카드를 클릭하면 먼저 아래 정보가 표시된다.

- **문제 개수**
  문제 카드 안에 저장된 문제의 개수. 카드 안에 등록된 문제들의 개수로 표현된다.
- **문제 카드 설명**
  이 문제 카드에서 어떤 문제가 나오는지 표시한다. (예: 이미지에 표시된 포켓몬스터의 이름을 맞힌다)
- **문제 카드 표지**
  문제 카드에 사용하는 썸네일
- **조회수**
  해당 문제 카드의 조회수.
  조회한 IP를 기준으로 인메모리에 만료 시간 6시간짜리 토큰을 만들어, 6시간 동안은 조회수가 다시 올라가지 않게 한다.
- **좋아요**
  로그인한 사람만 누를 수 있고, 한 번 더 누르면 좋아요가 취소된다.
  좋아요가 일정 수 이상 쌓이면 카드에 인기 문제 별표와 테두리 하이라이트가 붙어 시각적으로 눈에 띄게 바뀐다.
- **싫어요**
  로그인한 사람만 누를 수 있고, 한 번 더 누르면 싫어요가 취소된다.
  일정 수 이상 쌓이면 문제 카드가 숨김 처리된다.
- **풀이 개수**
  문제 카드에 들어 있는 문제 중 최대 몇 개까지 풀지 고른다.
  10개, 20개, 30개, 모두 풀기 버튼과 숫자를 직접 입력하는 칸으로 받는다.

문제 카드에서 시작 버튼을 누르면 카드 안의 문제 중 하나씩 랜덤으로 출제된다.
제한 시간은 없으며, 문제 유형에 맞는 템플릿으로 출제된다. (아래 [문제 유형](#문제-맞추기--문제-유형) 참고)

### 문제 맞추기 — 시작

시작 버튼을 누르면 문제 유형에 따라 문제가 랜덤으로 출제된다.
각 유형에 맞는 형태로 출제되며, 사용자는 주관식, 객관식, O/X 중 하나로 답한다.

- **주관식**: 입력 칸에 답을 입력한다.
- **객관식**: 최대 5지선다 중 하나를 클릭해서 답한다.
- **O/X**: O 또는 X를 골라서 답한다.

정답을 맞히면 "정답입니다!", 틀리면 "오답입니다"라는 문구를 화면에 띄운다.
틀렸을 때는 정답을 보여주지 않고, 맞혔을 때만 정답을 함께 보여준다.

#### 랭킹

모든 문제가 끝나면 TOP 10 랭킹을 보여준다.

- 내가 10등 안에 들면 랭킹 목록에서 내 순위(예: 5등)를 하이라이트한다.
- 10등 밖이면 1~10등을 보여주고, 맨 아래에 내 순위(예: 15등 ○○○)를 따로 표기한다.

로그인한 사용자는 로그인 정보로 랭킹에 등록된다.
로그인하지 않은 사용자는 화면에서 닉네임을 입력받아 그 닉네임으로 등록되며, 로그인한 유저와 구분하기 위해 닉네임 앞에 자동으로 "익명의"가 붙는다. (예: 익명의XXX)

- 비로그인 사용자는 같은 닉네임이 있는지 중복 체크가 필요하다.
- 비로그인 사용자는 같은 사람이 여러 번 풀어도 판마다 따로 등록된다.

랭킹은 맞힌 개수와 얼마나 빨리 맞혔는지로 매긴다.
기본 계산식은 **맞힌 개수 × 10점 + 문제별 풀이 시간 점수**이다.

| 문제 하나당 걸린 시간 | 점수 |
|---|---|
| 0초 이상 ~ 3초 미만 | 4점 |
| 3초 이상 ~ 5초 미만 | 3점 |
| 5초 이상 ~ 8초 미만 | 2점 |
| 8초 이상 ~ 11초 미만 | 1점 |
| 11초 이상 | 0점 |

#### 유저 포인트

위의 랭킹은 해당 문제 카드에 대한 랭킹이다. 이와 별개로 유저 포인트가 있다.

- "모두 풀기"로 모든 문제를 맞히면 유저 포인트 20점을 지급한다.
- 유저 포인트는 나중에 여러 치장 아이템이나 멀티플레이 기능을 도입할 때 여러 방면으로 쓰이는 방향으로 기획한다.
- 이미 정복한 문제 카드는 다시 풀어도 점수가 오르지 않는다.
- 이미 모두 풀어서 점수가 오르지 않는 문제 카드는 화면에서 따로 하이라이트하는 식으로 유저가 바로 알 수 있게 한다.

### 문제 맞추기 — 문제 유형

문제 카드 안에서 문제를 등록할 때는 먼저 문제 유형을 정하고 등록한다.

- **이미지형**: 이미지가 첨부된 문제
  가운데에 이미지가 뜨고, 좌우 버튼으로 최대 5장까지 이미지를 보여줄 수 있다.
  이미지 아래에 부가 설명(텍스트)을 넣을 수 있다.
- **텍스트형**: 텍스트(설명)만으로 이루어진 문제
- **소리형**: 소리를 듣고 푸는 문제
  아래에 부가 설명(텍스트)을 넣을 수 있다.
- **복합형**: 이미지, 텍스트, 소리를 모두 결합한 유형
  **1차 MVP에서는 제외한다.**

### 문제 맞추기 — 답변 유형

- **주관식**
  띄어쓰기와 대소문자를 구분하지 않고 정답 처리한다.
  복수 정답과 비슷한 정답을 어떻게 처리할지는 논의가 필요하다. (개발 단계에서 유사도 계산 등)
- **객관식**
  보기는 제작자가 직접 입력하며, 최대 5지선다까지 지원한다.
- **O/X**
  O 또는 X 중 하나를 정답으로 정한다.

### 댓글 시스템

문제 카드를 클릭하면 하단에 해당 문제 카드의 댓글이 표시된다.

- 로그인과 비로그인 모두 댓글을 작성할 수 있다.
- 로그인한 경우 로그인한 닉네임으로 작성하며, 댓글 수정·삭제가 가능하다.
- 비로그인인 경우 "익명의XXX" 형태로 닉네임이 표시된다. 작성할 때 비밀번호를 입력받고, 그 비밀번호를 입력하면 수정·삭제할 수 있다.
- 대댓글을 달 수 있으며, 형태는 댓글과 같다.
- 댓글에는 신고 버튼이 있다. 신고가 5번 이상 쌓이면 해당 댓글은 "신고로 인해 가려진 댓글입니다"로 보이게 처리한다.

### 댓글 시스템 — 칭호

문제를 맞힐 때마다 점수를 얻고, 그 점수에 따라 댓글 옆에 칭호를 표시한다.

칭호의 점수 기준은 아직 정하지 않았지만, 우선 0~100점은 U, 101~1000점은 R 같은 식으로 티어를 표시할 수 있어야 한다.

치장 관련 시스템은 점수를 차감하는 방식이 아니라, 누적 점수로 해금하는 방식으로 진행한다.

### 댓글 시스템 — 닉네임 꾸미기

문제를 맞힐 때마다 점수를 얻고, 점수가 일정 이상(5000점)을 넘으면 닉네임에 다양한 효과(애니메이션, 글자색 바꾸기 등)를 줄 수 있다.

우선은 글자색 바꾸기만 허용한다.

치장 관련 시스템은 점수를 차감하는 방식이 아니라, 누적 점수로 해금하는 방식으로 진행한다.

### 문제 생성

문제 생성은 로그인과 비로그인 모두 가능해야 한다.

- 로그인한 계정은 로그인 정보로 문제를 생성한다.
- 비로그인인 경우 닉네임과 비밀번호를 입력하고, 그 정보로 수정·삭제할 수 있다.

문제 생성 버튼을 누르면 먼저 문제 카드를 만드는 화면으로 이동한다.

- 문제 카드에는 썸네일 사진, 문제 명칭, 공개 여부 등을 등록할 수 있다.
- 공개 여부는 기본이 비공개이며, 안에 등록된 문제가 10개를 넘어야만 공개로 바꿀 수 있다.

문제 카드가 만들어지면 카드 안에 들어가서 문제를 등록할 수 있다.
문제를 등록할 때는 문제 유형을 선택한 뒤 진행한다.
